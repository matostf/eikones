# Licence of the images

The MIT licence in `LICENSE` covers the code (`baixar.py`, `hash_manifesto.py`,
`normalizar_manifesto.py`, `folha_contato*.py`, `folha-contato.html`) and the
curation metadata (`MANIFESTO.csv`, `MANIFESTO.json`, `README.md`).

It does **not** cover the images. Each `.jpg` / `.png` in the repository root
keeps the licence recorded for it on Wikimedia Commons, stated per file in the
`licenca` column of `MANIFESTO.csv` (Public domain, CC0, CC BY or CC BY-SA,
with version and jurisdiction), with the attribution in `autor` / `credito`
and the source page in `pagina_commons`.

- Public domain and CC0 files: no attribution required (credit is still given
  in the manifest as good practice).
- CC BY files: attribution required when reused.
- CC BY-SA files: attribution required, and derivatives must carry the same
  licence.

No image in this collection is under a non-commercial or no-derivatives
licence.
